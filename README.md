# Siddhant's Portfolio Website


A modern, responsive portfolio website showcasing my projects, skills, and experience. Built with pure HTML, CSS, and JavaScript.


<img width="1901" height="912" alt="image" src="https://github.com/user-attachments/assets/2ec8cd5e-c371-44a3-b3fc-6918ff506ea7" />


## 🚀 Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean and professional design with smooth animations
- **Interactive Elements**: Dynamic typing effect and smooth scrolling
- **Project Showcase**: 5 real projects with descriptions, tech stacks, and GitHub links
- **Skills & Experience**: Technical skills, internship history, and certifications
- **Working Contact Form**: Messages are delivered straight to my inbox via Formspree - no backend required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Formspree (contact form backend)

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Sidd-commits/My-portfolio.git
   ```

2. Open `index.html` in your web browser to view the website locally.

3. To make the contact form work on your own copy, sign up free at [Formspree](https://formspree.io), create a form, and replace `YOUR_FORM_ID` in the `<form action="...">` line in `index.html` with your own form ID.

## 🎨 Customization

### Personal Information
- Update your name, title, and description in the hero section
- Modify the projects section with your own projects
- Update the experience section with your skills and expertise
- Change the contact information with your details

### Styling
- The main styles are in `styles.css`
- Colors and fonts can be easily modified in the CSS file
- Responsive breakpoints can be adjusted as needed
